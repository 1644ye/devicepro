ZEN65 有线100%来自真实原生状态回复；固件ADC上游在有线调度中继续更新，因此不是固定USB满电占位。充电仍未知：UI的0/1/2映射与该固件回复状态字节的低电标志用途冲突，软件保留原始状态诊断，不将0解释成未充电。官方Fn+Backspace数字键灯约10%档位是另一条设备本地显示路径，不冒充主机读数。详见 [调查记录](ZEN65-RESEARCH.md) 与 [固件静态证据](ZEN65-LOCAL.md)。

ROG OMNI 使用多个接口且与其他型号共享 VID/PID。本版本在每次电量读取前重新确认配对列表中只有一个可安全选定的 Mini，避免把共享接收器误认成具体鼠标。接收器回复 0 电量且未充电的休眠空状态不作为有效本体读数，不覆盖上次电量时间。完全耗尽电池的边界语义仍需实机补测。

其他待实机项目：ROG 关机但接收器保留、真实拔插和连接模式切换、与 Armoury Crate 同时访问、真实睡眠/恢复、真实 Explorer 崩溃重启、混合 DPI 与多屏拔除、系统登录静默自启。测试中的 Windows 消息注入和 fixture 仅验证软件路径，不替代这些硬件/系统实测。
